# FEMA ICS Form 205 v3.1 source

`ics-form-205-v3.1.pdf` is the official FEMA Incident Radio Communications Plan
form used as the artwork and field-layout template for toolkit exports.

- Official source: <https://training.fema.gov/emiweb/is/icsresource/assets/ics%20forms/ics%20form%20205,%20incident%20radio%20communications%20plan%20(v3.1).pdf>
- Retrieved: 2026-08-20
- SHA-256: `cbe54dc5ae6de7af1d01f5c84c68031645f5d92b095763b3667ed13efd872377`
- Version shown on form: ICS 205, March 2018

FEMA states that government-produced Independent Study materials are generally
public domain under 17 U.S.C. 105 unless otherwise marked. The toolkit preserves
the official artwork, populates its existing fields, and flattens the result. It
does not claim FEMA endorsement or alter the underlying form design.

Before replacing this file, confirm the source is an official FEMA publication,
review the form fields and rendered output, update the pinned checksum, and run
the plans PDF tests.
